# Stakeholder interview guide (prepared questions)

> **Status: prepared, not yet asked.** These questions are meant for real interviews with a loan officer, an operations
> manager and a risk/compliance colleague. Do not present answers as real unless you have asked them. The BRD marks
> its requirements as *assumed* for this reason.

## Operations manager
1. Which loan products are slowest to approve, and what is the target turnaround time?
2. Do you track where applications wait today? With which report?
3. If one step could be automated this quarter, which would you choose and why?
4. What does one extra day of cycle time cost (customers lost, staff time)?
5. How would you want to receive results: dashboard, weekly report, workshop?

## Loan officer
6. Which steps do you repeat for the same application, and why does it come back?
7. Which tasks are routine rule checks and which need your judgement?
8. Which information is often missing when you start a step?
9. What would make you trust an automatic recommendation?

## Risk and compliance
10. Which steps must always have a human decision?
11. What must be logged for an automatic action to be audit-ready?
12. Are there fairness or regulatory checks before changing an approval process?

## Data / IT
13. Which system produces timestamps for each step, and how reliable are they?
14. Can an event log with case id, activity, start and end time be exported without personal data?
